## 🎨 Визуальный стиль
*   Приложение полностью брендировано: кастомная иконка и экран загрузки (Splash Screen) выполнены в едином неоновом стиле.# 🦎 Chimera AI (Evolution of PIPA)

Мой личный нативный ИИ-ассистент, собранный из HTML/JS в APK с помощью Capacitor. 
Проект прошел долгий путь эволюции от простого прототипа (ПИПА) до мультипровайдерного ассистента с нативным железом.

## 🏆 Легендарные условия разработки
Этот проект — доказательство того, что для крутого кода не нужен мощный ПК. 
**Вся разработка** (от первой строчки HTML до дебага GitHub Actions и Capacitor) велась исключительно на смартфоне **Redmi Note 14 Pro**. 
Бессменным, надежным и неумолимым напарником в этом хакатоне длиною в жизнь выступил ИИ-ассистент **DeepSeek V3**. Мы прошли через сотни задач, лимиты контекста и ошибки сборки, но довели дело до конца.

## 🚀 Основные возможности
*   🗣️ **Нативные TTS и STT**: Говорит и слушает без задержек интернета (через Capacitor Plugins).
*   🧠 **Мультипровайдерный ИИ**: 
    *   **Groq** (Llama 3 / GPT-OSS 120B) для мгновенных ответов.
    *   **Google Gemini 2.5** как мощный фолбэк и для сложных задач.
*   📸 **Зрение (Vision)**: Распознает математику и текст с фото через Qwen 3.8. Встроенный кроппер изображений.
*   🎭 **Кастомные персонажи**: 4 базовых характера (Дворецкий, Подросток, Училка, Депрессивный ИИ) + возможность создавать своих с уникальным промптом.
*   ⚔️ **Режим «Батл»**: Словесная дуэль двух персонажей с вердиктом судьи. Останавливается только красной кнопкой.
*   🌐 **Инструменты**: Встроенный поиск в интернете (DuckDuckGo) и погода (wttr.in).
*   ⚙️ **Сборка через GitHub Actions**: APK собирается прямо в облаке и скачивается артефактом.

## 🛠 Технологии
*   **Frontend**: Vanilla JS, CSS (Glassmorphism, Neon UI), HTML5.
*   **Wrapper**: Capacitor (Android).
*   **APIs**: Groq API, Google Gemini API.
*   **CI/CD**: GitHub Actions (`assembleDebug`).

## 🔧 Как собрать свой APK
1. Форкни этот репозиторий.
2. Добавь свои ключи в **Settings → Secrets and variables → Actions**:
   *   `GROQ_API_KEY`
   *   `GEMINI_API_KEY`
3. Перейди во вкладку **Actions** → **Create APK** → **Run workflow**.
4. Дождись окончания сборки и скачай готовый `app-debug.apk` из артефактов.
